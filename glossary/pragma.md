PRAGMA is an open-source association that backs independent Cardano implementations and shared infrastructure, so the ecosystem is not tied to a single node codebase. Projects such as the [Amaru](/glossary/amaru) node sit in that broader multi-implementation effort. Style guide: write the name in all caps as PRAGMA.
